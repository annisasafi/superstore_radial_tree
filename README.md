# Tentang Dashboard
Diagram ini menampilkan struktur hierarki data transaksi Superstore dengan susunan:
Root → Year → Quarter → Category
1.  **Root**: All Regions Superstore
2.  **Year**: 2023, 2024, 2025, 2026
3.  **Quarter**: Q1, Q2, Q3, Q4
4.  **Category**: Furniture, Technology, Office Supplies

## Fitur

- Warna node berbeda tiap level hierarki
- Ukuran node kategori proporsional berdasarkan nilai Sales
- Hover tooltip menampilkan detail Sales, Profit, dan Orders
- Animasi garis saat pertama kali dimuat

## Dataset

1.  **Sumber**: Sample Superstore Dataset
2.  **Total Orders**: 10.194 transaksi
3.  **Total Revenue**: $2,297,201
4.  **Periode**: 2023 – 2026

## Tech Stack
1. D3.js v7
2. HTML5 / CSS3 / Vanilla JavaScript
